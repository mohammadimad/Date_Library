# مكتبة التاريخ بلغة C++

مكتبة تعليمية بلغة C++ مبنية على الأصناف لتمثيل التواريخ والتدرب على الحسابات التقويمية. يقدّم صنف `clsDate` دوالًا ساكنة وأخرى تعمل على كائن التاريخ.

## المزايا المنفذة

- إنشاء التاريخ من تاريخ النظام أو نص بصيغة `يوم/شهر/سنة` أو أجزاء رقمية أو ترتيب يوم داخل السنة
- قراءة قيم اليوم والشهر والسنة وتعديلها
- اكتشاف السنة الكبيسة وحساب الأيام والساعات والدقائق والثواني في السنة أو الشهر
- تحويل التاريخ إلى نص ومن النص
- طباعة تقويم شهر أو تقويم سنة كاملة
- حساب ترتيب يوم الأسبوع ومقارنة تاريخين
- زيادة التاريخ أو إنقاصه بالأيام والأسابيع والأشهر والسنوات والعقود والقرون والآلاف
- حساب الفرق والعمر بالأيام وأيام العمل والإجازات وتاريخ العودة منها
- التحقق من صحة التاريخ وحساب ترتيب اليوم داخل السنة

## التقنيات والمفاهيم

- C++
- البرمجة كائنية التوجه
- الدوال الساكنة ودوال الكائن
- خصائص Microsoft الخاصة باستخدام `__declspec(property)`
- Visual Studio وMicrosoft Visual C++

## إعداد البناء

المشروع مضبوط على أداة Visual Studio 2019 المسماة `v142` ولا يحتوي على ملف Solution.

1. افتح `Date Library.vcxproj` في Visual Studio.
2. ثبّت v142 أو أعد استهداف المشروع إلى أداة C++ مثبتة.
3. اختر `Release | x64` ثم ابدأ البناء.

```powershell
msbuild "Date Library.vcxproj" /p:Configuration=Release /p:Platform=x64
```

## التحقق من البناء

حُل تعارض نسختي `IncreaseDateByOneDay` عبر الإبقاء على الدالة التي تستقبل مرجعًا وتعدّل التاريخ الممرر إليها. نجحت إعادة بناء Release كاملة باستخدام أداة v145 المثبتة، كما انتهى تشغيل البرنامج التجريبي برمز خروج `0`.

ما زال المترجم يعرض تحذيرين غير مانعين للبناء: فاصلة منقوطة إضافية بعد أمر `#include`، وتحويل `size_t` إلى `short`.

## النطاق الحالي

- يفترض البناء من النص إدخال قيمة سليمة بصيغة `يوم/شهر/سنة` ولا يعالج النصوص غير الصحيحة بأمان.
- تستخدم عدة عدادات النوع `short` مما يحد من النطاقات المدعومة.
- قواعد عطلة الأسبوع وأيام العمل ثابتة داخل الكود وليست قابلة للإعداد.
- المكتبة تعليمية وليست مكتبة إنتاجية للمناطق الزمنية أو اللغات أو الجدولة.

## تحسينات مقترحة

- معالجة تحذيرات المترجم المتبقية
- استبدال العدادات الضيقة بأنواع أعداد وأحجام مناسبة
- التحقق من النص قبل الوصول إلى أجزاء التاريخ
- إضافة عمليات غير متغيرة واستخدام `const` وتسمية واضحة للدوال المعدّلة
- إضافة اختبارات للسنوات الكبيسة وحدود الأشهر والتواريخ غير الصالحة وفروق التواريخ
- دراسة أنواع التقويم الحديثة في مكتبة C++ `<chrono>`
